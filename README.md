# MC_Datapack_Player_Commands
Datapack for Minecraft to allow Fire spreads to be toggled on/off and difficulty (Easy, Normal, Hard) to be changed by all users in the server. 


Usage: MC 26.2, specifically for the fire toggle, Fire spreads placeholder has changed in recent updates. I specifically made this mod to allow my siblings to toggle basic commands on and off like they would in bedrock. The commands activate hard or easy mode for 10 minutes, or until a user leaves. The default difficulty is normal. Fire spreads is default off but can be toggled to 128 radius around player with /fire-on.

Commands:
/hard - hard mode for 10 minutes
/easy - easy mode for 10 minutes
/normal - back to default state
/fire-on - fire spreads is turned on for 10 minutes, 128 radius around player
/fire-off - fire spreads is now turned off, 0 radius
